# Madabina visual identity

Use this skill for visual work that represents the Madabina brand. Read [the visual identity reference](references/visual-identity.md) before selecting brand assets or applying visual styles.

For public-site or merchant-dashboard interface work, also read [the UI patterns reference](references/ui-patterns.md). It distinguishes the marketing site from the merchant panel and records observations from the current public page and the user-provided dashboard screenshot.

## Apply the identity

- Identify the product, surface, audience, and existing design system first. Preserve established product tokens unless the user asks for a redesign.
- Use the official logo asset suited to the background. Do not redraw, distort, crop, or recolor a logo to create an unverified variant.
- Treat the colors and typography in the reference as verified current product usage, not as a complete universal design-token specification. Do not invent official fonts, colors, or logo variants.
- Keep text and controls legible, preserve keyboard focus visibility, and do not communicate meaning through color alone.
- For French, English, and Arabic surfaces, preserve the requested language and support correct right-to-left layout for Arabic.
- If a brand rule is missing or current products disagree, describe the ambiguity and use the target product's established identity instead of claiming a universal rule.
